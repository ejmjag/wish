01 / Wish & If only

Wish + Past Simple

Қазіргі жағдайға көңіл толмау

wish + subject + Past Simple

Қазір университеттен алыс тұрамын. Тілек шынайы қазіргі жағдайға қарама-қарсы.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазіргі шындық: алыс тұрады

→
ТІЛЕК / ӨКІНІШ

Арман: жақын тұру

I wish I lived closer to my university.Университетіме жақынырақ тұрсам ғой.
I wish I knew the answer.Жауабын білсем ғой.
Жылдам тексеру

I wish I ___ closer to university.

02 / Wish & If only

Wish + were

Be етістігімен тілек

wish + subject + were

Ресми және емтихандық ағылшын тілінде барлық жақпен were қолдану қауіпсіз: I were, she were. Ауызекі тілде was кездеседі.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазіргі шындық: бойы қысқарақ

→
ТІЛЕК / ӨКІНІШ

Арман: бойы ұзын болу

I wish I were taller.Бойым ұзынырақ болса ғой.
I wish she were here.Ол осында болса ғой.
Жылдам тексеру

I wish she ___ here now.

03 / Wish & If only

Wish + Past Perfect

Өткен іске өкініш

wish + subject + had + V3

Өткен шақтағы жағдайды енді өзгерту мүмкін емес. Past Perfect өткенге өкінішті білдіреді.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Өткенде: аз дайындалды

→
ТІЛЕК / ӨКІНІШ

Қазір: соған өкінеді

I wish I had studied harder for the exam.Емтиханға көбірек дайындалғанымда ғой.
I wish I had not missed the train.Пойыздан қалып қоймағанымда ғой.
Жылдам тексеру

I wish I ___ harder last year.

04 / Wish & If only

Wish + would

Өзгенің әрекеті өзгерсе деген тілек

wish + subject + would + V1

Would көбіне басқа адамның мінез-құлқының өзгеруін немесе мазалайтын жағдайдың тоқтауын білдіреді. Әдетте өз еркімізбен басқара алатын өз әрекетіміз үшін I wish I would түрін қолданбаймыз.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазір: көршілер шулап жатыр

→
ТІЛЕК / ӨКІНІШ

Тілек: тыныштық орнаса

I wish my neighbours would stop making noise.Көршілерім шулауды қойса ғой.
I wish it would stop raining.Жаңбыр тоқтаса ғой.
Жылдам тексеру

I wish the neighbours ___ making noise.

05 / Wish & If only

Wish + could

Мүмкіндік немесе қабілет туралы тілек

wish + subject + could + V1

Could — қазіргі немесе болашақтағы мүмкіндік пен қабілеттің жетіспеуі. Өткенде істей алмаған іске өкініш үшін wish + had been able to немесе wish + could have + V3 қолданылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазір: еркін сөйлей алмайды

→
ТІЛЕК / ӨКІНІШ

Арман: еркін сөйлеу

I wish I could speak English fluently.Ағылшынша еркін сөйлей алсам ғой.
I wish I could join you tomorrow.Ертең сендерге қосыла алсам ғой.
Жылдам тексеру

I wish I ___ speak French.

06 / Wish & If only

If only + Past Simple

Қазіргі тілек, күштірек эмоция

If only + subject + Past Simple

If only көбіне wish-ке қарағанда күштірек эмоция білдіреді. Қазіргі шындыққа қарама-қарсы тілекке Past Simple қолданылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазір: уақыты аз

→
ТІЛЕК / ӨКІНІШ

Тілек: көбірек уақыт

If only I had more free time!Бос уақытым көбірек болса ғой!
If only we lived by the sea!Теңіз жағасында тұрсақ қой!
Жылдам тексеру

If only I ___ more time now!

07 / Wish & If only

If only + Past Perfect

Өткенге қатты өкініш

If only + subject + had + V3

Өткенде болған немесе болмаған әрекетке өкініш. Болымды да, болымсыз да түрде қолданылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Өткенде: құжат сақталмады

→
ТІЛЕК / ӨКІНІШ

Қазір: өкінеді

If only I had saved the document!Құжатты сақтап қойғанымда ғой!
If only I had listened to her advice!Оның кеңесін тыңдағанымда ғой!
Жылдам тексеру

If only I ___ the document yesterday!

08 / Wish & If only

If only + would

Жағдай өзгерсе деген күшті тілек

If only + subject + would + V1

Көбіне күтіп отырған өзгеріс не басқа адамның әрекеті туралы айтылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазір: автобус кешігіп жатыр

→
ТІЛЕК / ӨКІНІШ

Тілек: автобус келсе

If only the bus would come!Автобус келсе екен!
If only he would answer my message!Ол хабарыма жауап берсе екен!
Жылдам тексеру

If only the bus ___ soon!

09 / Wish & If only

Wish vs Hope

Арман мен ықтимал үміттің айырмасы

wish + unreal past form / hope + ordinary tense

Hope — орындалуы мүмкін жағдайға үміт; wish — шындыққа қайшы тілек немесе өкініш. Hope-тен кейін әдеттегі шақтар қолданылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Hope: нақты мүмкіндік

→
ТІЛЕК / ӨКІНІШ

Wish: шындыққа қайшы тілек

I hope I pass the exam. / I wish I knew all the answers.Емтиханнан өтемін деп үміттенемін. / Барлық жауапты білсем ғой.
I hope she comes.Ол келеді деп үміттенемін.
Жылдам тексеру

I ___ I pass the exam tomorrow.

10 / Wish & If only

Wish vs Would / Could

Would және could мағыналық айырмасы

would = өзгеріс / could = мүмкіндік

Would — басқа адамның әрекетіндегі не жағдайдағы өзгеріс; could — өз қабілетің немесе мүмкіндігің.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Would: әрекет өзгерсін

→
ТІЛЕК / ӨКІНІШ

Could: мүмкіндік болсын

I wish he would call me. / I wish I could call him.Ол маған хабарласса ғой. / Мен оған хабарласа алсам ғой.
I wish the internet would work.Интернет жұмыс істесе ғой.
Жылдам тексеру

I wish he ___ me, but I wish I ___ call him.

11 / Wish & If only

Wish vs Conditionals

Тілек пен шартты нәтиже

wish + past form / if + condition, result

Wish тек тілекті білдіреді; conditional шарт пен нәтижені байланыстырады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Wish: тек тілек

→
ТІЛЕК / ӨКІНІШ

Conditional: шарт + нәтиже

I wish I had a car. / If I had a car, I would drive to work.Көлігім болса ғой. / Көлігім болса, жұмысқа көлікпен барар едім.
If only I had a car!Көлігім болса ғой!
Жылдам тексеру

If I had a car, I ___ to work.

12 / Wish & If only

Болымсыз түрлер

Not және had not қолданылуы

wish + subject + did not / had not / would not

Қазіргі болымсыз тілекке did not + V1; өткенге өкінішке had not + V3; өзгеріс тілеуге would not + V1 қолданылады.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Қазір: алыс тұрады

→
ТІЛЕК / ӨКІНІШ

Тілек: алыс тұрмаса

I wish I did not live so far away.Осындай алыс тұрмасам ғой.
I wish he would not interrupt me.Ол сөзімді бөлмесе ғой.
Жылдам тексеру

I wish I ___ so far away.

13 / Wish & If only

Сұрақ және хабарлы сөйлем

Wish формасын сөйлемде қолдану

Do you wish ...? / I wish ...

Do you wish ...? — тілек туралы сұрақ. I wish I knew ... құрылымында knew — өткен уақытты емес, шындыққа қайшы қазіргі жағдайды білдіреді.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Сұрақ: тілегі бар ма?

→
ТІЛЕК / ӨКІНІШ

Жауап: I wish ...

Do you ever wish you lived abroad?Шетелде тұрсам ғой деп ойлайсың ба?
I wish I understood this rule.Осы ережені түсінсем ғой.
Жылдам тексеру

Do you ever wish you ___ abroad?

14 / Wish & If only

Өткен мүмкіндік

Could have және had been able to

wish + subject + could have + V3

Өткенде мүмкіндік болмағанына өкініш. I wish I had been able to attend the meeting түрі де дұрыс.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Өткенде: қатыса алмады

→
ТІЛЕК / ӨКІНІШ

Қазір: өкінеді

I wish I could have attended the meeting.Жиналысқа қатыса алғанымда ғой.
I wish I had been able to help.Көмектесе алғанымда ғой.
Жылдам тексеру

I wish I ___ able to help yesterday.

15 / Wish & If only

Wish + noun / wish somebody

Тұрақты тіркестер

wish somebody + noun / wish to + V1

Бұл қолданыстар unreal wish емес. Wish somebody luck / happiness және ресми wish to + V1 = want to.

НАҚТЫ ЖАҒДАЙ / БҰРЫН

Тілек: good luck

→
ТІЛЕК / ӨКІНІШ

Ресми: wish to speak

I wish you good luck!Саған сәттілік тілеймін!
I wish to speak to the manager.Мен менеджермен сөйлескім келеді.
Жылдам тексеру

I wish ___ speak to the manager.

Негізгі айырмашылықтар

ФормаМағынасыМысал
wish + Past SimpleҚазіргі шындыққа қарсы тілекI wish I knew.
wish + Past PerfectӨткенге өкінішI wish I had known.
wish + would + V1Басқа адам/жағдай өзгерсеI wish he would listen.
wish + could + V1Қабілет/мүмкіндікI wish I could swim.
if only + unreal formКүштірек тілек/өкінішIf only I had known!

Есте сақта: Past Simple әрқашан өткен уақытты білдірмейді. Wish және If only сөйлемдерінде ол қазіргі шындыққа қарсы мағынаны білдіре алады.
